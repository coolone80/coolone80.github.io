개인정보처리방침

드라이브 플레이어 (Drive Player) · 시행일 2026-10-02

드라이브 플레이어(이하 "앱")는 사용자 본인의 Google Drive에 있는 오디오 파일을 재생하기 위한 개인용 Android 앱입니다. 앱은 별도의 서버를 운영하지 않으며, 사용자 데이터를 개발자에게 전송하지 않습니다.

1. 접근하는 정보

  • Google 계정 로그인 정보: Google 로그인을 통해 Drive 접근 권한을 받기 위해서만 사용합니다.
  • Google Drive 파일 읽기 (drive.readonly): 사용자가 지정한 폴더의 파일 목록(파일 이름, 크기, 생성일)과 오디오 파일 내용을 읽어 재생합니다. 앱은 기존 Drive 파일을 수정하거나 삭제하지 않습니다.
  • 앱이 만든 파일 쓰기 (drive.file): 재생목록·이어듣기 위치·완료 표시 같은 앱 사용 기록을 사용자 본인의 Drive에 music_streaming_data.json 파일로 저장하고 읽습니다. 이 권한으로는 앱이 직접 만든 파일에만 접근할 수 있습니다.

2. 정보의 사용 목적

위 정보는 오디오 파일 목록 표시, 재생, 재생 기록의 저장·복원에만 사용합니다. 광고, 분석, 프로파일링, 머신러닝 학습 등 다른 목적으로는 사용하지 않습니다.

3. 저장 위치

  • 사용자 기기: 곡 목록 캐시, 앱 설정(지정한 폴더 등), 재생한 오디오의 스트리밍 캐시(최대 2GB).
  • 사용자 본인의 Google Drive: 앱 사용 기록 파일(music_streaming_data.json 및 백업 파일).

개발자나 제3자의 서버에는 어떤 정보도 저장되지 않습니다.

4. 제3자 제공

앱은 사용자 정보를 판매하거나 제3자에게 제공·공유하지 않습니다. 앱이 통신하는 곳은 Google 로그인 및 Google Drive API(Google LLC)뿐입니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

6. 데이터 삭제와 권한 철회

  • 앱을 삭제하면 기기에 저장된 캐시와 설정이 모두 삭제됩니다.
  • Drive에 저장된 music_streaming_data.json 파일은 사용자가 Drive에서 직접 삭제할 수 있습니다.
  • 앱의 Google 계정 접근 권한은 Google 계정 > 보안 > 서드파티 액세스에서 언제든 철회할 수 있습니다.

Privacy Policy (English summary)

Drive Player is a personal Android app that plays audio files from the user's own Google Drive. It reads the file list and audio content of a folder chosen by the user (drive.readonly) and reads/writes only the app-created file music_streaming_data.json in the user's Drive (drive.file) to store playlists and playback progress. Data is stored only on the user's device and in the user's own Google Drive. The app has no backend server, does not sell or share user data with third parties, and does not use it for advertising or analytics. Drive Player's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at myaccount.google.com/permissions. Contact: GitHub 이슈 (github.com/coolone80/coolone80.github.io/issues)
